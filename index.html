    About the shield

    Clean by design,
    honest by default.

    ADD NOW stores your queue only on this device and uses YouTube’s privacy-enhanced embed mode. Direct media links play without extra ad layers from this app.

    A useful limitationWeb apps cannot remove ads injected inside YouTube or Vimeo players. ADD NOW does not claim to bypass those services or their terms.

    Creator search setup

    Connect YouTube search.

    Enter a YouTube Data API v3 key to search channel names and browse their public uploads. The key stays in this browser’s local storage and is sent only to Google’s API.

    For safety, restrict the key to YouTube Data API v3 and this site’s HTTP referrer. Open Google Cloud Console ↗
